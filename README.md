# Local Newsletter Network

Platform for launching and operating AI-assisted local newsletters across many European cities (DACH first)
from a single codebase: ingest → draft → approve → send, plus events calendar,
business directory, sponsor portal, self-hosted SES mailer and sales pipeline.

Start with [docs/MARKETS.md](docs/MARKETS.md) for the target-market research,
[docs/PLAYBOOK.md](docs/PLAYBOOK.md) for the operating playbook, [docs/SEO-BRAND.md](docs/SEO-BRAND.md)
for brand, domains and SEO, and
[docs/PLAN.md](docs/PLAN.md) for the business model, run-rate costs,
architecture, scaling plan and market-selection method.
